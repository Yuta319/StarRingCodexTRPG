# イベント表示文テンプレート作成用チェックシート

このファイルは、**イベント生成システム用の表示文テンプレート**を作る際の共通フォーマットです。  
目的は、**量産しても日本語が崩れにくいこと**、**設計文と表示文を分離すること**、**Codexで再利用しやすいこと**です。

---

## 使い方

1. 新しいイベントを作るたびに、このテンプレートを複製する。
2. まず「基本情報」と「設計メモ」を埋める。
3. 次に「表示文の骨組み」を作る。
4. その後で本文を書く。
5. 最後に禁止語・自然さ・選択肢をチェックする。

# 13. 記入例

## 基本情報

- **イベントID**: `false_hero_whisper`
- **イベント名**: `偽英雄の囁き`
- **種別**: `scene`
- **主カテゴリ**: `神秘 / 噂 / 認知反転`

## このイベントの機能

- **このイベントで起きること**: `主人公を英雄視する噂が広がる`
- **このイベントで変わること**: `名声上昇、偽英雄アーク進行`
- **このイベントで残るもの**: `噂、違和感、作為の気配`
- **次につながる要素**: `教会接触`

## 表示文の骨組み

- **1行目**: `最初は宿でこぼれる軽口だった`
- **2行目**: `別の場所でも同じ話を聞く`
- **3行目**: `誰かが後ろで噂を広げている気配がある`
- **4行目**: `聞き流せなくなる`

## 表示文ドラフト

```text
最初は、宿でこぼれる軽口の類だった。
だが、その軽口を別の人間まで口にし始めると、話は少しずつ色を変える。
あいつはただ者じゃない——そんな囁きが、広場の端から端へじわじわと広がっていた。
しかも妙なのは、その広がり方だった。誰かが後ろで、その噂を都合よく大きくしている気配がある。
```

# 14. Codex向け運用メモ

```text
このMarkdownテンプレートに従って、イベント表示文を作成してください。

表示文は3〜6文、情景先行、抽象語を避け、行為動詞を必ず2つ以上含めてください。
```
