Editor Troubleshooting

よくある失敗だけを先に見る

Action import が失敗する

OpenAPI の servers.url が live API を指し、Actions Setup の Server URL と一致しているか確認する。

py -3 scripts\open_gpt_publish_workspace.py --copy actions_server_url
Privacy URL が通らない

Builder Website と Privacy Policy URL が両方ともブラウザで 200 で開くことを確認する。

py -3 scripts\run_custom_gpt_publish_smoke.py --retries 2 --retry-delay-seconds 1.0
新規開始の導入が弱い

`guidance.openingPackage` を使い、確定前の内容を案として扱っているか確認する。

py -3 scripts\open_gpt_publish_workspace.py --open
finalizeCharacter が失敗する

request に `world_json` が入っているかを確認し、Preview Test Pack の新規開始フローから再試行する。

py -3 scripts\prepare_gpt_publish_release.py --retries 2 --retry-delay-seconds 1.0
