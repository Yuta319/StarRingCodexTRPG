# Privacy Policy and Publish Checklist v1

## Required before public sharing/publishing
- A valid public Privacy Policy URL for every public action
- A builder profile website link from a verified domain if you want that shown publicly
- A working action domain reachable from the imported OpenAPI spec

## Suggested URLs
- Builder profile website: `https://policy.star-ring-codex.com`
- Privacy Policy: `https://policy.star-ring-codex.com/privacy.html`

If you later publish the apex domain, you can switch these URLs after confirming they are live.

## Policy page should include
- What the GPT is
- What Actions it can call
- What data is sent to the backend
- What is and is not persisted
- That raw free action text is not persisted as canon truth
- Contact / operator information

## Builder/Profile notes
- Use the verified domain you control
- Make sure the privacy policy URL is live before turning on public sharing/publishing
- Re-test Actions after any version restore or auth change
