Builder Profile

Star Ring Codex

Star Ring Codex is a PBW-style narrative TRPG shell built around a generated world, a session archive, and a Custom GPT narrator that reads backend truth instead of inventing canonical state.

What It Does

Generated Starts, Fixed Truth

On a fresh start, the world, session-one pressure, opening cast, and inciting incident are generated. After that, the backend stores the canonical world state and the GPT works as narrator and guide.

Surface

Chat + Overlay Shell

The experience combines a Custom GPT conversation layer with an overlay UI for character setup, codex browsing, equipment, assets, and relation views.
