Star Ring Codex Custom GPT Actions

This page describes how the public Custom GPT actions for Star Ring Codex handle data.

What the actions receive

  • Session state sent as world_json or generated from a supplied seed.
  • Player action text for free actions and structured choice requests.
  • Character setup proposals when the player finalizes a new-game opening.

How the data is used

  • To generate the next world state, update the session archive, and build a read model for the GPT and UI.
  • To save or load a session only when the player explicitly requests it.
  • To keep canonical state on the backend so the GPT narrates from backend truth instead of inventing state.

What is not done

  • No public social feed, ad profiling, or third-party analytics are used by these action routes.
  • Player data is not sold.
  • The GPT is not allowed to mutate truth directly without going through backend constraints.

Operational note

Saved session files can contain player-provided text and generated world state. Treat exported or saved session files as private game data.
